# HSdeck Rastakhans Rumble 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## API 경량화·편집 지침 (2026-11-14)

- 공개 파일은 `cards.json`, `data/<CARD_ID>.json` 카드별 날짜 기록, `art/`, `golden/` 일반/황금 원화와 애니메이션, `frame/` 프레임·셰이더·텍스처입니다. 원본 `data/history.json`은 중앙 날짜 이력/빌드 입력이므로 삭제하지 않습니다.
- 루트의 `render.json`, `history.json`은 중복/호환 출력으로서 더는 Git에 커밋하지 않습니다. 빌드 및 XML 회귀 검사에서 생성하더라도 임시 산출물로만 사용합니다. 검증에 필요한 `sources/`, `tests/`, `tools/`, `.github/`는 유지합니다.
- 한국 날짜 기준 실제 대전 최초 사용 가능일(베타 북미 시각 변환, 모험 지구 개방, 이벤트 실제 시작)과 토큰·선택지를 검증합니다. 사전 추가일과 출시일을 혼동하지 않으며 과거 오기입 키를 삭제·통합합니다.
- 날짜별 첫 상태와 후속 변경 필드를 분리합니다. 미확정 내용을 검증된 값으로 격상하지 않고 표시용 줄바꿈만 `<br></br>`로 정리합니다. 원화·황금 애니메이션·프레임 원본 바이너리는 변형하지 않습니다. 불필요한 schema/호환 래퍼를 만들지 않습니다.
